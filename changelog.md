# Changelog

All notable changes to the current version of the project will be documented in this file. For a full list of changes please reference the [full changelog](https://github.com/PseudoElephant/ArcaneRelay/blob/master/changelog-full.md).

## v1.3.7
- Migrated the project architecture to use Gradle instead of Maven. This decision was made as there was additional tooling available for Hytale modding with a Gradle based repository.
- Started using [HytaleTools](https://github.com/AzureDoom/Hytale-Gradle-Plugin)
- Modified README.md to have up to date instruction on the project setup.
- Added two changelog files. `changlog-full.md` and `changlog.md` and updated them accordingly.
